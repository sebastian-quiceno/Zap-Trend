>[!IMPORTANT]
>
>Este programa es solo un proyecto personal para poner en practica `SQL`, `C#`, `HTML`, `CSS` y `TypeScript`, **NO** se tiene intenciones de venderlo o utilizarlo en un **Entorno REAL**

## Que es Zap Trend

Zap Trend es una aplicacion la cual permite a cualquier negocio implementar su propia aplicacion E-Commerce para: 

- Administrar Roles de usuarios
- Administrar clientes
- Administrar productos
- Crear pedidos
- Confirmar pedidos
- Cancelar pedidos
- Generar facturas
- Notificar mediante eventos las acciones importantes del sistema

>[!NOTE]
>
>Puede profundizar en las funcionalidades en: [Requisitos y Alcance](./Doc/README.md).
